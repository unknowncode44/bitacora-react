# React + TypeScript + Vite

Para iniciar un proyecto de react con Typescript y Vite corremos los siguientes comandos en nuestra consola (dentro del directorio donde queremos situar nuestro proyecto)

``` # Crear proyecto con Vite y TypeScript
npm create vite@latest bitacora-react -- --template react-ts
cd bitacora-react
npm install
# Iniciar servidor para mostrar la velocidad de Vite
npm run dev ```
